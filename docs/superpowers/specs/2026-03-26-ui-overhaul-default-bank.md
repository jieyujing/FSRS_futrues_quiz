# 期货刷题助手 UI 升级与默认题库持久化方案

## 1. 目标 (Goals)
*   **默认题库持久化**：用户能够记录并自动加载默认题库（科目），提升连续使用的便捷性。
*   **交互式 UI 升级**：提升首页与刷题页的视觉魅力和交互体验，采用方案 A（以科目为中心的设计）。
*   **交互增强**：引入动态反馈、平滑过渡和微动效。

## 2. 技术设计 (Technical Design)

### 2.1 默认题库管理 (Default Bank Management)
*   **存储机制**：使用前端 `localStorage` 存储 `f_practice_default_subject`。
*   **逻辑流程**：
    1.  首页加载时从 `localStorage` 读取 `default_subject`。
    2.  如果没有记录，则从后端获取统计数据后，默认选择第一个科目或“全部题目”。
    3.  用户在首页点击“开始刷题”或在科目列表中选择时，更新 `localStorage`。
    4.  刷题页 (`Practice.tsx`) 在初始化时优先请求 `default_subject` 下的题目。

### 2.2 首页 UI 升级 (Home Page Overhaul)
*   **视觉风格**：采用卡片式布局，增加阴影和圆角效果。
*   **科目卡片 (Subject Card)**：
    *   展示科目名称、总题数、已学进度（百分比）。
    *   Hover 特效：卡片轻微上浮（`translateY(-4px)`）并伴随半透明蓝色发光。
*   **快速入口**：顶部显眼位置展示“上次学习科目”，提供“继续学习”按钮。

### 2.3 刷题页交互增强 (Practice Page Enhancement)
*   **答题反馈 (Feedback FX)**：
    *   **Correct**: 选项背景瞬间变为浅色渐变绿，并有向上微弹效果。
    *   **Incorrect**: 错误选项伴随左右震动，并显示正确选项。
*   **进度条动画**：顶部进度条使用 `transition: width 0.3s ease-in-out`。
*   **解析展示**：内容淡入效果，而不是瞬间出现。

### 2.4 全局交互优化
*   **页面切换**：使用 CSS 透明度过渡。
*   **响应式适配**：确保移动端也具有良好的点击反馈。

## 3. 成功标准 (Success Criteria)
*   刷新页面后，首页能正确显示上次练习的科目。
*   首页科目卡片具有顺滑的浮起效果。
*   刷题时点击选项有明显的视觉反馈动画。
*   整体视觉风格比当前版本更具质感。
