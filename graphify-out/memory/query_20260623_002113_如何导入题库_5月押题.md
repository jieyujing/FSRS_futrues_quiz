# Q: 如何导入题库“5月押题”

## Answer

Expanded from original query via vocab: [import, importer, importing, bank, 批量导入题库脚本, docx].

从 Polanyi 的默会维度（Tacit Dimension）与内居（Indwelling）视角来看，导入题库的过程涉及我们对代码工具的身体整合与协同认知。具体导入步骤如下：

1. **工具定位**：
   题库导入的核心逻辑由 backend/scripts/import_questions.py 提供，它会默认扫描项目根目录下的 doc 文件夹，读取并解析其中的 .pdf 或 .docx 文件。

2. **分析潜在的识别冲突**：
   通过对元数据提取器 MetadataExtractor 的代码分析发现，当前“5月押题”文件夹下的文件名（如 LK法规答案（四）.pdf）使用的是括号式数字 （四），而 MetadataExtractor 默认正则仅支持类似 第X套 的匹配。如果直接放入 doc/ 导入，所有文件的套号都会被默认识别为 Set 1。

3. **两种导入方案**：
   - **方案 A（重命名匹配）**：将“5月押题”下的文件重命名为符合正则格式的文件名，例如 2026年5月LK押题 法规第四套.pdf，然后将其复制到根目录下的 doc 文件夹中。
   - **方案 B（代码扩展）**：修改 backend/app/services/metadata_extractor.py 中的 _try_default 函数，增加对括号数字（如 （四））的解析。

最后，进入 backend 目录激活虚拟环境并执行：
cd backend
python scripts/import_questions.py
